Présentation de l'application

Ce que fait l'outil, à qui il s'adresse, comment il s'insère dans le workflow

Objectif

Web Refactor Studio accélère la phase d'avant-vente et de production lors d'une refonte web. En partant d'une simple URL, l'outil analyse automatiquement un site existant, génère un mockup HTML redesigné, permet de le personnaliser visuellement, puis exporte un brief structuré vers Claude Code pour la production.

À qui s'adresse cet outil

Freelances web et petites agences qui font de la refonte. L'outil est particulièrement utile lors de la phase d'avant-vente pour produire rapidement une proposition visuelle convaincante, et en phase de production pour structurer le brief technique vers Claude Code.

💡
Gain de temps estimé : un mockup personnalisé avec rapport d'audit est générable en moins de 10 minutes après réception de l'URL client.

Cas concret 1

Analyse du site client existant → audit + mockup redesigné → brief Claude Code

🎯
Contexte : Un client vous contacte avec son site actuel. Il veut un devis de refonte et une idée visuelle de ce que pourrait donner le nouveau site. Vous n'avez que l'URL.
1
Scraper le site client
Ouvrez http://localhost:3456, collez l'URL du site client. Réglez la profondeur sur 2 pour capturer l'accueil et les pages principales. Laissez Screenshots et ZIP activés. Cliquez Lancer l'analyse et attendez la fin (3–5 min selon la taille du site). Le mockup se génère automatiquement à la fin.
2
Consulter le rapport d'audit
Dans l'historique, cliquez report.md. Vous obtenez un rapport complet avec : score global /10, points forts à conserver, problèmes UX, problèmes SEO, freins à la conversion, recommandations classées (quick wins / refonte / long terme), estimation de coût. Ce rapport est directement envoyable au client.
3
Ouvrir le Studio et choisir un preset
Cliquez 🎨 Studio. Dans l'onglet STYLE, dépliez la famille de presets correspondant au secteur client. Cliquez le preset adapté — le mockup se met à jour instantanément dans la preview.
  • Restaurant → Restaurant gastro
  • Profession libérale → Juridique ou Corporate
  • Artisan, commerçant local → Chaleureux local ou Artisan
  • Startup, SaaS → Tech moderne ou SaaS / B2B
4
Affiner couleurs et typographies
Onglet COULEURS → ajuster la couleur primaire pour correspondre à la charte du client (si elle existe). Onglet TYPO → choisir des polices Google Fonts cohérentes avec l'identité de marque. Chaque modification s'applique en temps réel dans la preview.
5
Générer les 3 variantes et choisir
Cliquer ⚡ 3 variantes dans la barre de pages. Puis ⚖ Comparer pour voir les 3 options côte à côte. Choisir la variante la plus convaincante → cliquer "✓ Choisir" pour l'appliquer au Studio. Ces 3 variantes peuvent aussi être présentées directement en visio avec le client.
6
Remplir le brief et exporter le prompt
Onglet BRIEF : renseigner secteur, cible, ton éditorial, stack technique souhaitée. Cliquer 💾 Sauvegarder puis ✨ Générer Prompt. Copier le prompt généré → le coller dans Claude Code pour démarrer la production.

Livrables de ce cas

📄 Rapport d'audit (report.md)
Envoyable directement au client. Justifie la refonte et valorise la prestation.
🖥 Mockup HTML statique
Aperçu visuel du futur site. S'ouvre dans n'importe quel navigateur.
⚖ Comparateur 3 variantes
Page HTML autonome présentant les 3 options de style côte à côte.
✨ Prompt Claude Code
Brief technique structuré avec toutes les données extraites du site. Prêt pour la production.

Cas concret 2

Site de référence + site client existant → redesign inspiré de la référence

🎯
Contexte : Vous avez trouvé un site de référence premium (concurrent, inspiration sectorielle) dont vous voulez vous inspirer pour le redesign du client. L'objectif est d'appliquer le style visuel de la référence au contenu et à la structure du site client.
1
Scraper le site de référence en premier
Ouvrez http://localhost:3456, collez l'URL du site de référence (ex: un concurrent premium dans le même secteur que le client). Profondeur 1 suffit généralement — vous cherchez uniquement le design system, pas tout le contenu. Lancez et attendez la fin.
2
Scraper le site client
Saisissez ensuite l'URL du site client. Profondeur 2 pour capturer accueil + pages principales. Lancez l'analyse. Le mockup client se génère automatiquement à la fin.
3
Ouvrir le Studio du site CLIENT
Dans l'historique, sur la carte du site client (pas la référence), cliquez 🎨 Studio. Le mockup généré à partir du contenu du client s'affiche dans la preview.
4
Importer le style du site de référence
Onglet STYLE → section "Site de référence" en haut du panneau. Saisissez le domaine de la référence dans le champ texte, ou sélectionnez-le dans la liste déroulante. Cliquez la flèche bleue →. Les swatches de couleur et les polices détectées sur le site de référence s'affichent. Cliquez Appliquer les couleurs et/ou Appliquer la typo selon vos besoins.
5
Ajuster et personnaliser
Le mockup client adopte maintenant l'identité visuelle de la référence. Affinez dans les onglets :
  • COULEURS → retoucher les teintes si nécessaire
  • TYPO → adapter si les polices de référence ne correspondent pas
  • SECTIONS → activer/désactiver selon la structure propre au client
  • LAYOUT → ajuster les espacements si la mise en page diffère
6
Valider avec les 3 variantes
Cliquer ⚡ 3 variantes → ⚖ Comparer. En visio avec le client, ouvrez compare.html directement dans le navigateur pour une comparaison impactante. Le client choisit → ✓ Choisir applique la variante.
7
Enrichir le brief et exporter
Onglet BRIEF → remplir les champs de contexte. 💾 Sauvegarder → ✨ Générer Prompt. Le prompt intègre à la fois les données du site client et les choix stylistiques inspirés de la référence.

Livrables de ce cas

📄 Rapport d'audit client
Diagnostic du site actuel + argumentaire pour la refonte.
🖥 Mockup fusionné
Contenu client + style de référence. Démontre le potentiel du redesign.
⚖ Comparateur 3 variantes
Outil de décision pour le client. Idéal en présentation visio.
✨ Prompt Claude Code
Brief enrichi avec les données des deux sites. Démarre la production directement.
💾 theme.json exporté
Thème sauvegardé — réutilisable pour des itérations ou d'autres projets du même secteur.

Structure des fichiers générés

Organisation du dossier output/ après analyse

output/
└── domaine.com/
    ├── analysis/
    │   ├── audit.json         ← framework, libs, complexité technique
    │   ├── content.json       ← H1, CTAs, formulaires, navigation
    │   ├── design-system.json ← couleurs et typographies détectées
    │   ├── report.md          ← rapport d'audit complet (envoyable client)
    │   └── sitemap.json       ← structure et liste des pages
    ├── mockup/
    │   ├── index.html         ← mockup principal redesigné
    │   ├── variant-a.html     ← variante Professionnel
    │   ├── variant-b.html     ← variante Premium
    │   ├── variant-c.html     ← variante Chaleureux local
    │   ├── compare.html       ← comparateur 3 variantes côte à côte
    │   └── theme.json         ← thème sauvegardé depuis le Studio
    └── screenshots/         ← captures d'écran par page analysée
💡
Partager les fichiers : le dossier output/domaine.com/ est autonome. Vous pouvez le zipper (bouton ZIP activé au scraping) et l'envoyer ou l'archiver tel quel.

Raccourcis et astuces

Problèmes fréquents et bonnes pratiques

SituationSolution
La preview ne charge pasAttendre que le spinner disparaisse — le mockup se charge en iframe. Si le problème persiste, cliquer "⚡ Générer le mockup" visible dans la preview vide.
Le preset ne s'applique pasVérifier que le mockup est bien généré avant d'ouvrir le Studio.
Site de référence introuvableScraper d'abord le site de référence, puis relancer l'import depuis le Studio.
Présenter au clientOuvrir compare.html directement dans le navigateur — aucun serveur requis, fonctionne en offline.
Sauvegarder une versionExport JSON depuis le Studio → stocker le fichier. Rechargeable via le bouton "Charger".
"Serveur non disponible"Le serveur n'est pas démarré. Lancer npm run server dans le terminal.
Modifier le mockup après coupRouvrir le Studio : les modifications précédentes sont rechargées depuis le localStorage.
Proposer plusieurs directionsUtiliser les 3 variantes comme base de discussion. Une fois la direction choisie, affiner dans le Studio.
